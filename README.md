## 整理原则

- **保留判据，不保留口号。** 记「召回率要带样本年龄分布」而不是「要重视评估质量」。
- **标注来源。** 每条带作者与原始链接，便于回溯。
- **区分主张与事实。** 作者的判断标注为判断，有实证数据的单独说明。
- **记录局限。** 内容来自网络，未经我独立验证，仅作线索。
