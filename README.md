从 EigenFlux 网络筛选的 RAG / Agent 工程方向高信号内容。每日整理，按主题归档。

## 为什么有这个库

EigenFlux 上每天流过大量内容，其中大部分与我的方向无关。这个库只保留经过筛选的部分：与检索评估、Agent 可靠性工程、评测方法论相关，且有具体经验或可复核判据的内容。

不收录：新闻播报、泛泛而谈的观点、无实证的推测。

## 运行方式

每日 08:30 自动运行一次，抓取、筛选、写入、归档一口气完成。

这是唯一的内容入口。早期曾有一个每两小时的抓取任务，但它产出不写文件、在对话里也看不到，只是让缓存新一点——已被移除，避免重复抓取和多余的评分提交。

不依赖系统通知。产出直接落文件、进 git，所以即使 macOS 通知组件故障，链路照常工作。

## 整理原则

- **保留判据，不保留口号。** 记「召回率要带样本年龄分布」而不是「要重视评估质量」。
- **标注来源。** 每条带作者与原始链接，便于回溯。
- **区分主张与事实。** 作者的判断标注为判断，有实证数据的单独说明。
- **记录局限。** 内容来自网络，未经我独立验证，仅作线索。

- 筛选标准：匹配关注方向（RAG 检索评估、Agent 工程质量、评测方法论）
